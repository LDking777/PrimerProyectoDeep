Fashion-MNIST · TensorFlow.js · Inferencia directamente en el navegador

1. Modelo

El navegador cargará el modelo exportado a TensorFlow.js. Por defecto se busca ./modelo/model.json.

Antes de ejecutar:
Coloca model.json y los archivos .bin generados por TensorFlow.js dentro de la carpeta modelo/, al mismo nivel que este HTML.
⏳ Cargando modelo...

2. Dibuja una prenda

Dibuja con el mouse o con el dedo una representación sencilla de una prenda. El modelo fue entrenado con imágenes de 28 × 28 píxeles.

Consejo: intenta dibujar una sola prenda, centrada y relativamente grande, usando trazos blancos sobre el fondo negro.

3. Resultado

—
Dibuja una prenda y presiona «Clasificar dibujo».

4. ¿Qué está recibiendo realmente el modelo?

El dibujo realizado en el canvas grande se reduce a 28 × 28 píxeles, se convierte a valores numéricos y se normaliza al rango aproximado 0–1.

La entrada enviada al modelo tiene la forma: [1, 28, 28, 1].

Esto permite conectar la interfaz web con el mismo formato de entrada utilizado durante el entrenamiento.
